# AI × Web3 School — Cohort 0

> Personal learning journal and proof-of-work for AI × Web3 School.

## 关于

AI × Web3 School 是一个面向 builders 的开源学习计划，系统学习 AI、区块链、智能合约、AI Agent 与去中心化 AI，并通过 Bootcamp 和项目实践连接真实协作。

- **Handbook**: https://aiweb3.school/zh/handbook/
- **WCB Bootcamp**: https://web3career.build/zh/programs/AI-Web3-School
- **GitHub 源码**: https://github.com/lxdao-official/aiweb3school
