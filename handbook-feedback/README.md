# Handbook Feedback

> 学习过程中发现的问题、卡点、错别字、概念不清楚、资料过期、结构建议，整理到这里。

## 提交流程

1. 每条反馈创建一个文件：`YYYY-MM-DD-short-description.md`
2. 文件内容包含：
   - Handbook 页面链接
   - 问题描述
   - 建议改法
   - 来源（自己的理解/讨论/实践）
3. 定期提交到 GitHub，或者通过 GitHub Issues 提交到上游

## 模板

```markdown
# Feedback: {{简短标题}}

- **日期**：
- **Handbook 页面**：
- **类型**：错别字 / 概念不清 / 资料过期 / 结构建议 / 其他

## 问题描述

## 建议改法

## 来源
```
